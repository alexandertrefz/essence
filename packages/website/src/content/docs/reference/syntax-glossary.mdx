Essence writes a good deal with punctuation that no other language spells the
same way. `§` opens a comment, `@` is the receiver, `::` calls a method and
`<-` answers with a value. Each of those is defensible on its own, and every
one of them is opaque the first time it is met.

This page is the decoder. It lists every form the
[Lexer](https://github.com/alexandertrefz/essence/blob/master/packages/compiler/src/lexer/index.ts)
produces and every shape the parser builds out of them, grouped by what kind of
thing it is. Each table is followed by a program that uses the forms in it; the
programs compile, and the output shown under them is what they print.

## Comments

<div class="table-scroll">

| Form | Means | Example |
| --- | --- | --- |
| `§` | A comment, running to the end of the line. A private note; nothing reads it. | `§ a note to a later reader` |
| `§§` | Documentation of whatever is declared directly below. Markdown, shown by the editor on hover. | `§§ Greets a subject.` |

</div>

There is no block-comment form. A comment ends at its line break, and a
`§§` block is the run of `§§` lines directly above a declaration — a blank line
or an ordinary `§` comment in between ends the run, and what is above it then
documents nothing.

<Note>
	The character is U+00A7, the section sign. Nothing else in the language
	uses it, and it ends an identifier the way a symbol does — `name§ note` is
	a name and a comment written flush against each other.
</Note>

```essence
§ An ordinary Comment runs to the end of its line and is a private note.

implementation {

	§§ Documentation for whatever is declared directly below it. The text is
	§§ Markdown, and an Editor shows it on Hover and next to a Completion.
	constant greeting = "Hello"

	§ A gap ends a run of `§§` lines, so this Comment documents nothing.
	Terminal.print(greeting) § A Comment may also trail a line of code.
}
```

```
Hello
```

## Sigils

<div class="table-scroll">

| Form | Means | Example |
| --- | --- | --- |
| `@` | The value in hand — the receiver inside a method body, the scrutinee inside a match arm, already narrowed, and the value under test inside a refinement's `where`. | `<- @::length()` |
| `::` | Calls a method on the value to its left. | `count::add(1)` |
| `::<Name>` | The same call, made through the namespace named, where more than one would fit. | `total::<Clock>formatted()` |
| `<-` | Answers with a value. The language's one return. | `<- message` |
| `->` | Introduces a return type — of a function, a method, a match. | `() -> String` |
| `#` | Names a case of a choice, both where one is built and where one is matched. | `case #Empty { <- 0 }` |
| `~>` | Types a record literal, where the shape alone would not say which type is meant. | `Point ~> { x = 0, y = 0 }` |
| `\|` | A union of the types on either side. | `Integer \| Rational` |
| `/` | Between two integers written flush against it, a rational literal. | `3/4` |
| `_` | Drops a parameter's label, so the argument is passed without one. | `_ value: Integer` |
| `_` | Between digits written flush against it, a group separator. | `1_000_000` |
| `_` | In matcher position, the case answering for everything the ones above did not name. | `case _ { <- 0 }` |
| `_` | As a whole parameter, one the body has no name for — with a type where nothing supplies one, without where the expected signature does. | `_: Integer`, `(_) { <- 0 }` |
| `.` | Reads a member — of a record, or of a namespace. | `here.x`, `Number.Pi` |
| `-` | Before a number literal, its negation. | `-7` |
| `\` | Inside a string literal, escapes the character after it. | `"she said \"hi\""` |

</div>

```essence
implementation {

	§ `@` is the receiver; `::` calls a Method on it; `<-` answers.
	namespace Doubling for Integer {
		twice() -> Integer {
			<- @::multiply(with 2)
		}
	}

	§ `_` drops a Parameter's label, `->` writes the return Type.
	function doubled(_ value: Integer) -> Integer {
		<- value::twice()
	}

	§ `|` builds a Union, `/` writes a Rational, `_` groups digits.
	type Amount = Integer | Rational

	constant half: Amount = 1/2
	constant million = 1_000_000

	§ `.` reads a Record member; `~>` types a Record Literal.
	type Point = { x: Integer, y: Integer }

	constant here = Point ~> { x = 3, y = 4 }

	§ `#` names a Case, and `{ … }` inside a String is an interpolation hole.
	constant rounded = 7/2::round(toward #Down)

	Terminal.print("{doubled(21)} at {here.x}, {half}, {million}, {rounded}")
}
```

```
42 at 3, 1/2, 1000000, 3
```

The seven escapes a string literal understands are `\"`, `\\`, `\{`, `\}`,
`\n`, `\r` and `\t`. `\{` and `\}` exist because a bare `{` opens an
interpolation hole; everything else is reported as `invalid-escape` rather than
passed through quietly.

```essence
implementation {

	§ A backslash escapes a quote, a backslash, or either brace.
	Terminal.print("she said \"hi\" \\ and wrote \{braces\}")

	§ `\n`, `\r` and `\t` are the three control characters with a spelling.
	Terminal.print("one\ttwo\nthree")
}
```

```
she said "hi" \ and wrote {braces}
one	two
three
```

## Brackets and separators

<div class="table-scroll">

| Form | Means | Example |
| --- | --- | --- |
| `{ … }` | A block — an implementation, a body, a match, the cases of a choice. | `if ready { <- 1 }` |
| `{ … }` | A record: `name: Type` where a type is written, `name = value` where a value is. | `{ x = 0, y = 0 }` |
| `{ … }` | A pattern, wherever a value is taken apart — see [patterns](#patterns) below. | `constant { x, y } = point` |
| `{ … with … }` | A copy of the record on the left with the members named changed. | `{ origin with y = 9 }` |
| `{ … }` | Inside a string literal, an interpolation hole holding an expression. | `"hello {name}"` |
| `[ … ]` | A list literal. | `[2, 3, 5, 7]` |
| `( … )` | A parameter list, an argument list, a case payload, a function type. | `doubled(21)` |
| `< … >` | Type parameters where they are declared, type arguments where they are applied. | `List<Integer>` |
| `:` | An annotation — a name's type, a record member's type, a parameter's type. | `count: Integer` |
| `=` | Binds — a declaration, an assignment, a record member, a matcher's exact value. | `constant n = 1` |
| `,` | Separates the entries of every list the language has. A trailing one is allowed. | `[3, 4, 5,]` |

</div>

An argument's label is written in front of its value with nothing between them:
`divide(by 3)`, `slice(from 1, to 3)`. That is why a label and a bare case need
telling apart by hand — see [where whitespace matters](#where-whitespace-matters)
below.

```essence
implementation {

	§ `[ … ]` is a List, `{ … }` a Record, `:` an annotation, `=` a binding.
	constant primes: List<Integer> = [2, 3, 5, 7]
	constant origin: { x: Integer, y: Integer } = { x = 0, y = 0 }

	§ `< … >` declares Type Parameters and applies Type Arguments.
	function firstOr<infer Item>(_ items: List<Item>, _ fallback: Item) -> Item {
		<- items::firstItem()::otherwise(fallback)
	}

	§ `( … )` holds a Parameter list, an Argument list and a Case payload.
	constant missing: Optional<Integer> = #Empty

	§ `,` separates every list the language has, and a trailing one is allowed.
	constant sides: List<Integer> = [3, 4, 5,]

	Terminal.print(firstOr(primes, 0)::toString())
	Terminal.print(missing::otherwise(0)::toString())
	Terminal.print("{origin.x}, {sides::length()}")
}
```

```
2
0
0, 3
```

## Declarations

<div class="table-scroll">

| Form | Means | Example |
| --- | --- | --- |
| `implementation` | The block every program is. Nothing may be written outside it but the two module sections. | `implementation { … }` |
| `constant` | Binds a name once, and never again. | `constant answer = 42` |
| `variable` | Binds a name that can be rebound. The value it holds is still immutable. | `variable count = 0` |
| `type` | Gives a shape a name. | `type Point = { x: Integer }` |
| `choice` | Declares the shapes a value can take, one nominal case each. | `choice Door { Open, Shut }` |
| `protocol` | Declares the methods a conforming type answers. | `protocol Measurable { … }` |
| `namespace` | Packs methods for a type it need not own. | `namespace Clock for Integer { … }` |
| `for` | Names the type a namespace targets. | `namespace Clock for Integer` |
| `function` | Declares a free function, which always carries a body. | `function greet(…) -> String { … }` |
| `static` | A method or property belonging to the namespace rather than to any one value. | `static noon = 43_200` |
| `overload` | Gathers the signatures that share one name. | `overload scaled { … }` |
| `infer` | Marks a type parameter that binds from the call rather than being written. | `<infer Item>` |
| `declarations` | The standard library's own opening block, in place of `implementation`. Refused anywhere else. | `declarations { … }` |

</div>

```essence
implementation {

	§ `type` names a shape.
	type Shape = { width: Integer, height: Integer }

	§ `protocol` declares what a conforming Type answers.
	protocol Measurable {
		area() -> Integer
	}

	§ `namespace … for … is …` packs Methods for a Type and conforms it.
	namespace Shapes for Shape is Measurable {
		§ `static` belongs to the Namespace rather than to any one value.
		static unit = { width = 1, height = 1 }

		area() -> Integer {
			<- @.width::multiply(with @.height)
		}

		§ `overload` gathers signatures that share one name.
		overload scaled {
			(by factor: Integer) -> Shape {
				<- { @ with width = @.width::multiply(with factor) }
			}

			(by factor: Integer, and other: Integer) -> Shape {
				<- { width = @.width::multiply(with factor),
				height = @.height::multiply(with other) }
			}
		}
	}

	§ `function` declares a free Function, `constant` and `variable` bind names.
	function areaOf(_ shape: Shape) -> Integer {
		<- shape::area()
	}

	variable current: Shape = { width = 3, height = 4 }

	current = current::scaled(by 2, and 3)

	Terminal.print(areaOf(current)::toString())
	Terminal.print(areaOf(Shapes.unit)::toString())
}
```

```
72
1
```

`declarations { … }` is the one declaration form a program may not write. It
unlocks the body-less native method signatures the standard library is built
from, and the compiler refuses it everywhere else with a diagnostic that says
so.

<div class="error-output">

```

   │ 
   │ Help: Open the Program with 'implementation { … }' instead.
───╯
```

</div>

## Modules

<div class="table-scroll">

| Keyword | Means | Example |
| --- | --- | --- |
| `import` | The block above the implementation, naming what this module takes from others. | `import { … }` |
| `export` | The block below the implementation, naming what this module offers. | `export { Rectangle }` |
| `from` | Names the file an imported entry comes from, as a relative path in a string. | `Rectangle from "./Geometry.es"` |
| `as` | Binds an entry under a local name of your choosing. | `unitSide as side from "./Geometry.es"` |

</div>

A program reads top to bottom: what it imports, what it does, what it exports.
Both section blocks are optional, and an `import` written below the
implementation or an `export` above it is reported as
`misplaced-module-section` rather than left to cascade.

<CodeWindow
	title="Geometry.es"
	class="code-bare"
	compact
	code={`implementation {

	type Rectangle = { width: Integer, height: Integer }

	constant unitSide = 1
}

export {
	Rectangle
	unitSide
}`}
/>

<CodeWindow
	title="Main.es"
	class="code-bare"
	compact
	code={`import {
	Rectangle from "./Geometry.es"
	unitSide as side from "./Geometry.es"
}

implementation {

	constant unit: Rectangle = { width = side, height = side }

	Terminal.print(unit::toString())
}`}
/>

```
{ width = 1, height = 1 }
```

## Control flow

<div class="table-scroll">

| Form | Means | Example |
| --- | --- | --- |
| `match` | Takes a value apart, one `case` per shape it can be. Its return type is required. | `match value -> String { … }` |
| `case` | One arm of a match: a type, a literal, a record shape, a choice case, or `_`. | `case #Empty { <- 0 }` |
| `if` | Branches on a boolean, and narrows what it proved inside the branch. | `if ready { … }` |
| `else` | The other branch, which narrows through the opposite question. | `} else { … }` |
| `define` | A definition by cases: it answers with the value of the first arm whose condition holds. An arm is `as value if condition`. | `define { … }` |
| `otherwise` | The last arm of a `define`, and the one that always holds. It is required. | `as 0 otherwise` |
| `with` | Inside braces, copies the record on its left. | `{ origin with y = 9 }` |
| `true`, `false` | The two boolean literals. | `constant ready = true` |

</div>

There is no loop statement. Iteration is a value-driven walk — `map`, `reduce`,
the `loop` family — so `<-` keeps its one meaning and an early exit stays an
ordinary value a match can see.

```essence
implementation {

	§ `choice` declares the shapes a value can take; each Case is a Record.
	choice Command {
		Scale { by: Integer },
		Reset,
	}

	§ `match` takes a value apart, `case` names one shape, `->` its answer.
	function applied(_ command: Command, to count: Integer) -> Integer {
		<- match command -> Integer {
			case #Scale(factor) { <- count::multiply(with factor) }
			case #Reset         { <- 0 }
		}
	}

	§ A `where` Guard narrows further; `case _` answers for everything left.
	function described(_ value: Integer | String) -> String {
		<- match value -> String {
			case Integer where @::isNegative() { <- "below zero" }
			case Integer { <- "{@}" }
			case _       { <- "not a number at all" }
		}
	}

	§ `if` and `else` branch on a Boolean.
	function reported(_ count: Integer) -> String {
		if count::isGreaterThan(10) {
			<- "many"
		} else {
			<- "few"
		}
	}

	§ `define` answers with the value of the first arm whose Condition holds,
	§ and `otherwise` is the arm that always holds.
	function graded(_ score: Integer) -> String {
		<- define {
			as "top marks" if score::isGreaterThanOrEqualTo(90)
			as "a pass"    if score::isGreaterThanOrEqualTo(50)
			as "not yet"   otherwise
		}
	}

	§ `with` copies a Record, changing the members it names.
	constant origin = { x = 0, y = 0 }
	constant moved  = { origin with y = 9 }

	Terminal.print(applied(#Scale({ by = 3 }), to 7)::toString())
	Terminal.print(applied(#Reset, to 7)::toString())
	Terminal.print(described(-4))
	Terminal.print(described("x"))
	Terminal.print(reported(11))
	Terminal.print(graded(60))
	Terminal.print("{moved.x}, {moved.y}")
}
```

```
21
0
below zero
not a number at all
many
a pass
0, 9
```

## Patterns

One grammar names the parts of a value, and it is written in five positions: a
match arm, a case payload, a parameter, a function literal and a declaration.
The braces are the record matcher's, so a member either binds, or constrains, or
does both.

<div class="table-scroll">

| Form | Means | Example |
| --- | --- | --- |
| `{ name }` | Binds the member to that name, whatever its type. | `constant { x } = point` |
| `{ name: Type }` | Constrains the member by type, and binds it. | `case { y: Integer }` |
| `{ name = value }` | Constrains the member by value, and binds nothing — the value is written there. A question, so a declaration and a parameter refuse it. | `case { x = 0 }` |
| `as` | Binds under a name of your choosing, where the member's own would shadow something. | `{ x as column }` |
| `{ … } as name` | In a case payload, names the payload whole beside its parts. | `case #Value({ x } as point)` |
| A nested pattern | A binder is a name or another pattern, which is the whole of the nesting. | `{ origin as { x, y } }` |

</div>

```essence
implementation {

	type Click = { x: Integer, y: Integer }
	type KeyPress = { key: String }

	constant point: Click = { x = 0, y = 7 }
	constant input: Click | KeyPress = point

	§ In a Declaration: a bare name binds, and `as` binds under another name.
	constant { x, y as row } = point

	Terminal.print("{x}, {row}")

	§ In a Match arm, where `name = value` may also constrain by value.
	Terminal.print(match input -> String {
		case { x = 0, y } { <- "the y axis at {y}" }
		case { x, y }     { <- "{x}, {y}" }
		case { key }      { <- key }
	})

	§ In a named Parameter, where the Pattern stands where the internal name goes.
	function area(
		of { width, height }: { width: Integer, height: Integer },
	) -> Integer {
		<- width::multiply(with height)
	}

	Terminal.print(area(of { width = 6, height = 7 })::toString())

	§ And in a Case payload, where `} as name` also names the payload whole.
	constant found: Optional<Click> = #Value(point)

	Terminal.print(match found -> String {
		case #Value({ x, y } as whole) { <- "{x}/{y}, of {whole.y}" }
		case #Empty                    { <- "nothing" }
	})
}
```

```
0, 7
the y axis at 7
42
0/7, of 7
```

## Words that are not keywords

Four of the words that look most like keywords are not ones. `is`, `where`, `as`
and `declarations` are ordinary identifiers that the parser recognises by content
in the few places they can only mean one thing. For the first two that is a debt
owed to the standard library — both are also method names and argument labels it
writes, and reserving either would take `::is()` and `keepEvery(where …)` away.
`as` is structural only where a binder or a `define` arm's value can follow it,
so a record is free to have a member of that name and `{ as as as }` binds it. For `declarations` it is that
nothing else begins a program with a bare identifier, so the `{` behind it is
enough to tell.

<div class="table-scroll">

| Word | Where it is structural | Where it is an ordinary name |
| --- | --- | --- |
| `is` | A namespace's conformance (`is Measurable`), a type parameter's bound (`<infer Item is Comparable>`). | The equality method — `"a"::is("a")`. |
| `where` | A refinement on a type alias, a guard on a match arm, the conditions of a conditional conformance. | An argument label — `keepEvery(where …)`. |
| `as` | An import's local name, a pattern's binder, the name a case payload is taken whole under, and the head of a `define` arm. | A record member — `{ as = 1 }`. |
| `declarations` | The standard library's opening block, recognised by the `{` that follows it. | Any name at all. |

</div>

```essence
implementation {

	§ `where` on a Type Alias declares a checked refinement.
	type Digit = Integer where @::isBetween(0, and 9)

	function placed(_ digit: Digit) -> Integer {
		<- digit::add(1)
	}

	§ `is` names a conformance here, and is an Argument label further down.
	protocol Sizeable {
		size() -> Integer
	}

	namespace Sizes for String is Sizeable {
		size() -> Integer {
			<- @::length()
		}
	}

	§ `is` bounds a Type Parameter, and `where` bounds a conformance.
	function sizeOf<infer Item is Sizeable>(_ item: Item) -> Integer {
		<- item::size()
	}

	§ Both are ordinary Identifiers everywhere else — this is the Method `is`,
	§ and `where` is a label the standard library writes.
	constant same = "a"::is("a")
	constant kept = [1, 2, 3]::keepEvery(where (item) { <- item::isOdd() })

	Terminal.print(sizeOf("essence")::toString())
	Terminal.print(same::toString())
	Terminal.print(kept::toString())
	Terminal.print(placed(7)::toString())
}
```

```
7
true
[ 1, 3 ]
8
```

It runs the other way too. Sixteen of the twenty-nine words the lexer treats as
keywords are also admitted wherever an identifier is expected — `with`,
`static`, `case`, `otherwise`, `infer`, `choice`, `import`, `export`, `from`,
`as`, `tests`, `test`, `suite`, `benchmark`, `expect` and `require` — so a name
may be any of them. The remaining thirteen are reserved: `if`, `else`, `type`,
`constant`, `variable`, `function`, `implementation`, `overload`, `match`,
`define`, `namespace`, `protocol` and `for`.

```essence
implementation {

	§ Sixteen of the Keywords are ordinary Identifiers wherever no block needs
	§ them, so a name may be one of them.
	constant with      = 1
	constant static    = 2
	constant case      = 3
	constant otherwise = 4
	constant infer     = 5
	constant choice    = 6
	constant import    = 7
	constant export    = 8
	constant from      = 9
	constant as        = 10
	constant tests     = 11
	constant test      = 12
	constant suite     = 13
	constant benchmark = 14
	constant expect    = 15
	constant require   = 16

	§ The last six of them are the Keywords the testing forms are written with.
	constant testing = [tests, test, suite, benchmark, expect, require]

	Terminal.print(
		Number.sum([with, static, case, otherwise, infer, choice])::toString(),
	)
	Terminal.print(Number.sum([import, export, from, as])::toString())
	Terminal.print(Number.sum(testing)::toString())
}
```

```
21
34
81
```

## Where whitespace matters

Line breaks and comments are discarded before the parser sees a token, and
there is no statement terminator — nothing separates one statement from the
next but the grammar running out. Six forms are the exception, and each is read
from where its tokens sit rather than from what they are.

<div class="table-scroll">

| Form | The rule | Written apart it means |
| --- | --- | --- |
| `1_000` | Digits, `_` and digits written flush against one another. | An integer, then a `_` with no reading of its own. |
| `3/4` | Numerator, `/` and denominator written flush. | An integer, then a `/` belonging to whatever is on its own line. |
| `Ordering#Less` | The `#` written flush against the choice's name. | `label #Case` — a labelled argument carrying a bare case. |
| `Holder<String>#Full` | And where type arguments come between, the `#` on the line the `>` closes on. | Refused, so the applied form cannot slip past the rule above. |
| `List<Integer>` | The `<` on the same line as the type it applies to. | A `<` opening the next declaration. |
| `Integer where …` | The `where` on the same line as the type it refines. | A statement of its own, beginning with the name `where`. |

</div>

Each of the six is a place where the same tokens have two honest readings, and
position is what picks between them. None of the rules refuses anything a
program means to say: an application and a refinement are written on one line
anyway, and a literal is written as one lexeme. Documentation is the seventh of
the kind, and reads position twice over: a `§§` block is the run of lines
directly above a declaration, which a gap ends, and a parameter takes one only
when it is written on a line of its own — otherwise the first parameter of
`function greet(…)` would claim the function's own.

```essence
implementation {

	§ `label #Case` with a space is a labelled Argument carrying a bare Case.
	Terminal.print(7/2::round(toward #Down)::toString())

	§ `Name#Case` written flush is a Case prefixed by the Choice it belongs to.
	Terminal.print(Ordering#Less::is(1::compare(to 2))::toString())

	§ `1_000` and `1/2` are one Literal each only because they are written flush.
	Terminal.print(1_000::add(1/2)::toString())
}
```

```
3
true
2001/2
```

The `::<Name>` form is the other place a namespace has to be spelled out, and
it needs no adjacency rule of its own: a `<` directly after a `::` can be
nothing but a namespace specifier.

```essence
implementation {

	§ Two Namespaces answer `formatted` for Integer.
	namespace Duration for Integer {
		formatted() -> String {
			<- "{@::quotient(dividingBy 60)}m"
		}
	}

	namespace Clock for Integer {
		formatted() -> String {
			<- "{@::remainder(dividingBy 60)}s"
		}
	}

	§ `::<Name>` says which of them the call means.
	Terminal.print(90::<Duration>formatted())
	Terminal.print(90::<Clock>formatted())
}
```

```
1m
30s
```

## What there is no syntax for

A glossary is also a list of what is absent, and several of these are the first
thing a reader tries.

<div class="table-scroll">

| Not in the language | Write instead |
| --- | --- |
| Operators — `+`, `-` as subtraction, `==`, `&&`, `<` as comparison | Method calls: `a::add(b)`, `a::is(b)`, `a::and(b)`, `a::isLessThan(b)`. |
| A statement terminator, `;` | Nothing. Line breaks are discarded and the grammar delimits statements. |
| A block comment, `/* … */` | A run of `§` lines. |
| `return` | `<-`. |
| Hexadecimal, binary and exponent numbers — `0xFF`, `0b101`, `1e5` | Decimal digits, grouped with `_`. |
| A decimal literal, `0.75` | A rational — `3/4`. There is no binary floating point in the language. |
| `null`, `undefined`, `nil` | `Optional<T>`, whose `#Empty` case says the absence out loud. |
| A loop statement | `map`, `reduce`, and the `loop` family. |

</div>

The operator row is worth a sentence, because it is not a matter of the parser
turning `+` away. `+` is not a reserved character at all — it lexes as an
ordinary identifier, so `1 + 2` reads as three statements and reports that `+`
is not declared. The language has no operator table to extend, no precedence to
learn, and no expression whose reading depends on one.
