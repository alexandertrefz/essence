Taught on: [Numbers](/docs/language/numbers).

`compare(to:withPrecision:)` returns `Optional<Ordering>`, so `Transcendental` does not conform to `Comparable`. The ordering methods of [`Number`](/docs/library/number#comparing) accept one: `3::isLessThan(Number.Pi)` is `true`.
